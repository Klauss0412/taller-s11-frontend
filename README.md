# Taller Práctico S11 - Página Personal HTML (NERV / EVA-02 Theme) 🔴🟠

Repositorio correspondiente al taller práctico de la asignatura **Diseño de sistemas en Internet**, donde se estructura una página personal en HTML inspirada visualmente en los colores de **Asuka Langley Soryu (Unidad EVA-02)** y la interfaz de **NERV**.

## 👤 Autor
* **Nombre:** Klauss Joseph Saavedra Rayo

## 🎯 Objetivo General
Identificar la estructura básica del frontend mediante HTML, organizando correctamente los elementos de una página web.

## 🛠️ Contenido y Etiquetas Utilizadas
El archivo `index.html` integra todos los elementos solicitados en la guía:
* `<html>`, `<head>`, `<body>`: Estructura principal del documento web.
* `<h1>` – `<h6>`: Encabezado principal con mi nombre (`<h1>`) y subtítulos jerárquicos (`<h2>`, `<h3>`, `<h6>`).
* `<p>`: Párrafo de presentación personal (22 años, nacido el 21 de marzo de 2003).
* `<ul>` y `<li>`: Listas desordenadas para mis habilidades (Inglés C1, armado/mantenimiento profesional de PC, reparaciones básicas) e intereses (motos deportivas Honda CBR600RR roja/Repsol, lectura de manga y manhwa).
* `<img>` y `<a>`: Imágenes alusivas a la Honda CBR600RR y Asuka Langley, junto con enlaces a mi perfil de GitHub y sitios favoritos.
